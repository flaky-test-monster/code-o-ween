    Look at the code instead

    The honest way: by hand

    Goal: two VS Codes that macOS treats as two apps — two Dock icons, two ⌘-Tab entries, two sets of logins. Profiles can't do that; they switch inside one app. The lightest version needs no copy: 

    alias code-side-a='code --user-data-dir ~/.vscode-side-a --extensions-dir ~/.vscode-side-a/extensions'

    Separate settings, extensions and logins, but still one "Code" in the Dock. Undo: delete ~/.vscode-side-a.

    The full costume takes six steps:

    1. Clone the app with cp -cR into ~/Applications. Free on APFS, ~900 MB after the next update.
    2. Add a launcher that passes --user-data-dir (and optionally --extensions-dir).
    3. New identity: change CFBundleIdentifier and display name in Info.plist. Leave CFBundleName alone.
    4. Own Keychain item: rename "name" in the copy's package.json.
    5. Re-sign ad hoc with codesign, and swap the icon.
    6. Disable updates with "update.mode": "none". Repeat after every VS Code update.

    Exact commands and cleanup: README, by hand. Transcribed from the script, not separately tested.

    The quick way, for the mad

    Code-o-ween does the six steps for you: pick a name, an emoji, a color. Each clone gets its own Dock icon, ⌘-Tab entry, GitHub and Microsoft logins, and settings. To macOS they are different programs, because they are.

    Try it: click a costume in the Dock below, or open and make another. Nothing here touches your computer.

    🍬 Treat

    • Separate Dock icons and ⌘-Tab entries.
    • Separate logins per project.
    • Tinted title bar and emoji, so you know where you are.
    • Pin a folder: open the app, get the project.
    • Your real VS Code stays untouched.

    🕸️ Trick

    • It's a re-signed clone. A careful hack, still a hack.
    • ~900 MB per disguise after updates.
    • Every VS Code update: code-o-ween refresh --all.
    • One Keychain prompt per disguise.
    • Tested on one Mac. Chrome doesn't work; others untried.

    If you must

    Clone the repository, then in Terminal:

    ./install.sh
code-o-ween gui

    Or from the command line:

    code-o-ween create "Main Project"   --emoji 🎃 --color orange --folder ~/code/main-project
code-o-ween create "Side Project A" --emoji 👻 --color purple --folder ~/code/haunted-todo
code-o-ween create "Side Project B" --emoji 🧛 --color red    --folder ~/code/spooky.dev

    Do you even need this?

    For different settings and extensions, use VS Code's built-in Profiles (File → New Profile). Code-o-ween only adds what Profiles can't: a separate app with its own icon, ⌘-Tab slot, and logins. Still keen? Read the README first.
